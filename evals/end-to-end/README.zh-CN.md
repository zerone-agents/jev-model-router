# 最终 auto 抽查任务

[English](README.md) | 简体中文

[cases.json](cases.json)保留从公开选模集选出的4题、生成请求选项及调用前固定的答案评分规则。它们是公开回归素材，不是新独立集或通用基准。

将每题`request`原样提交到`/v1/chat/completions`，使用inference凭证、已发布的模型描述和默认均衡模板。不要先route.inspect再用显式模型代替auto。不传人工token上限，供应商限制仍适用。等待完整SSE，累积正文，检查正常结束及所有帧公共model一致。提取题用严格schema限制形状，不提供答案值。

通过请求ID查询管理路由记录，核对jev_choice、两名候选和固定配置版本。简单答案与`expected`严格比较（整数答案可去首尾空白）；复杂答案按所有rubric项完整人工审阅，存在实质性矛盾则不通过。覆盖关键词、HTTP成功、JSON可解析都不能代替答案正确。保留错误或未完成结果，不选择性重试。

现有`go run ./evals`不实现此流式加人工审阅协议；本目录提供可复现请求和规则，不是新可执行运行器。原始回答与逐次元数据留本地。历史结果见[验收摘要](../../docs/acceptance/2026-09-29.zh-CN.md)。
