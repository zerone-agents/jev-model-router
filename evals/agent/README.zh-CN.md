# Agent 合成任务

[English](README.md) | 简体中文

[cases.json](cases.json)保留物流查询、库存约束分配、故障规则决策三个流程的合成来源、工具schema、依赖关系、标准答案和最终输出schema。这是公开回归素材，不是真实业务数据或隐藏基准。

此题集需要调用方实现工具循环；`go run ./evals`不执行这个循环。复现时将工具实现为本地模拟，按参数匹配fixture，未知参数返回错误，并保留实际assistant/tool历史。不可调用真实订单或部署API。流式工具调用按index累积，校验ID唯一性、名称、JSON参数和依赖顺序。依赖上个工具返回值的查询必须等待，独立查询允许并行。

取得全部必需来源后，保留历史、省略顶层tools，指定`response_format`为`json_schema`，`strict=true`，schema使用题目的`output_schema`。这是调用方阶段控制，不是路由功能。完整JSON与`expected`严格比较，主要评分不能悄悄剥除Markdown围栏。工具正确性单独计分，恢复成功不覆盖先前错误；截断和未完成与答案错误分开。本协议不人为限制输出token，供应商限制仍然适用；识别停滞工具循环并记为未完成。

每题分别执行真正的auto生成和显式模型路径，不选择性重试。完整结果留本地，只公开经审阅摘要。工单中的伪造指令是非可信任务数据，不是评测执行器的指令；该题不代表安全认证。

库存题标准答案为A6/B1/D4、运费31，可对可用库存范围穷举复核。本目录仅公开任务与复现协议，不声称提供了自动化Agent执行器。
