# 验证与评测

本地测试使用模拟 Jev 和生成端点，无真实密钥、无付费请求。覆盖配置原子性、24 小时幂等重放、进程退出恢复、auto 保留名称、角色隔离、模型映射、SSE 工具片段、取消、超时、记录降级及空库到重启的 CLI 工作流。

默认值 10s 决策、60s 首个有效事件、60s 流空闲、100ms 记录尝试、8 事件缓冲、16MiB 请求上限来自实现边界测试，非真实供应商性能指标。超时测试使用缩短的注入时限验证边界和取消。健康流不受首包时限约束；空内容事件不会延长空闲期。模型描述最长 4096 字符、提示词最多 16384 Unicode 字符（以机器 schema 为准）；生成输出由模型限额和调用方参数控制，首版支持 max_completion_tokens 16–10000000，仍受模型上下文容量预检。

[显式评测工具](../evals/README.md) 提供合成问答、代码、长文本、工具、图片、中英混合与指令冲突任务。先校准人工可接受模型集合，再比较 auto 与固定模型的集合命中、端到端延迟、独立 Jev/生成 usage 与费用；人工答案质量另外评审，缺失数据标 unknown。先建立真实基线后设置门槛。

已完成真实端点的小规模兼容性冒烟验证，覆盖官方 Jev 多候选选模、阿里云生成及路由记录查询。已验证的组合和限制见[兼容说明](compatibility.md)。逐次请求标识、时间、usage 和临时验收明细仅保存在本地忽略目录，不作为公开性能基准。

## 当前证据与评分边界

已建立小规模选模偏好和Agent诊断基线，见[验收摘要](acceptance/2026-09-29.zh-CN.md)。选模偏好在事前固定题集与门槛下通过；Agent工具过程仍有历史失败。尚未完成生产代表性质量、实际费用及可比较性能评估，不宣称经济收益或自动关闭Issue #1。

四项分别评分：工程约束看协议/认证/持久化测试；选模偏好看预先标注集合与重复一致性；生成质量看最终答案和工具过程；经济收益需独立价格与使用数据。格式正确不代表业务正确，截断/超时为未完成，不是模型能力不足的证据。保留失败，不选择性重试到成功。

使用[公开回归集](../evals/routing/README.zh-CN.md)可重复检查现有偏好。公开或用于调参后不得再称为独立验收集；新策略需另建未参与调参的题集并事前固定门槛。题目和合成工具数据可公开，真实响应、请求标识、详细用量和逐次日志继续留本地忽略目录。
